Claude Code plugin · token-log

공유 계정, 누가 얼마나 썼는지 남깁니다

Claude 계정 하나를 여럿이 같이 쓰면 사용량이 한 덩어리로만 보입니다. token-log는 누가, 어느 프로젝트에서, 토큰을 얼마나 썼는지를 공유 폴더에 자동으로 기록합니다. 창을 몇 주씩 켜 두어도 10분마다 쌓입니다.

공유 계정을 쓰는 분은 모두 설치해 주세요. 설치만 하면 자동으로 기록되고, 따로 실행할 것은 없습니다. 대화 내용은 기록하지 않습니다.

설치

  1. Node.js 확인

    터미널에서 버전이 나오면 됩니다. 없으면 nodejs.org에서 설치하세요.

    node -v

  2. 플러그인 설치

    Claude Code 안에서 한 줄씩 따로 입력합니다. 두 줄을 한 번에 붙여 넣으면 설치되지 않습니다.

    /plugin marketplace add leekyongju2/token-log
    /plugin install token-log@token-log

  3. 이름과 기록 폴더 입력

    설치하면 설정 창이 뜹니다. 세 칸을 채우세요. 나중에 바꿀 때는 Claude Code에서 아래 명령을 입력합니다.

    /plugin configure token-log
    항목넣을 값
    내 이름홍길동 (기록 폴더 안에 이 이름의 폴더가 생깁니다)
    기록 폴더모두가 접근하는 공유 폴더
    중간 기록 간격(분)그대로 10

    기록 폴더는 네트워크 드라이브(\\서버\공유\claude-token-log)나, OneDrive로 동기화한 SharePoint 폴더(예: C:\Users\내계정\회사명\팀 - 문서\claude-token-log)면 됩니다. SharePoint를 쓰면 모두의 기록이 한곳에 모입니다.

    이름을 비우면 UNSET-윈도우계정으로, 폴더를 비우면 내 PC의 ~/.claude/token-log에만 쌓입니다.

  4. 한도 % 기록 권장

    계정의 5시간 · 7일 한도를 몇 % 썼는지는 상태줄에만 들어옵니다. 같은 파일에 추가하세요.

    "statusLine": { "type": "command", "command": "node ~/.claude/token-log/bin/snapshot.js" }

    이미 상태줄 스크립트를 쓰고 있다면, 입력(JSON)을 읽은 다음 줄에 이 한 줄을 넣으면 됩니다.

    try { require(require('os').homedir() + '/.claude/token-log/bin/snapshot.js')(input); } catch {}

  5. 재시작하고 확인

    Claude Code를 다시 켜고 질문을 하나 해 보세요. 답이 끝나면 기록 폴더에 2026-09/내이름/…txt 파일이 생깁니다.

사용법

  • 따로 할 일은 없습니다. 답이 끝날 때마다 백그라운드에서 확인해 최대 10분에 한 번, 그리고 세션을 끝낼 때 한 번 더 기록합니다.
  • 창을 한 달 동안 안 꺼도 됩니다. 세션이 끝나기를 기다리지 않습니다.
  • 사용량을 보려면 Claude에게 "토큰 사용량 보여줘" 또는 /token-report.
/token-report --since 2026-10-01
/token-report --user 홍길동

읽는 법

  • 기록 하나가 파일 하나입니다(JSON 한 줄). 파일을 새로 만들기만 하고 고치지 않아서 동기화 충돌이 없습니다.
  • 기록 하나는 직전 기록 이후에 쓴 양입니다. 그래서 그냥 더하면 됩니다. 한 세션이 여러 기록으로 나올 수 있고 reason이 interim이면 중간 기록입니다.
  • total은 대부분 cache_read입니다. 캐시 읽기는 단가가 가장 싸서, 부담을 보려면 output · cache_write · API환산$을 보세요.
  • API환산$는 Claude Code가 계산한 정가 환산액입니다. 구독 청구액이 아닙니다.
  • 한도 +%p는 세션 동안 계정 전체 %가 오른 폭입니다. 같은 시간에 다른 사람이 쓴 몫이 섞이므로 추정치로 보세요.

알아둘 것

  • 답을 기다리는 시간은 늘지 않습니다. 기록은 백그라운드에서 합니다.
  • 창을 X로 닫아도 괜찮습니다. 다음에 Claude Code를 열 때 빠진 양을 따라잡아 기록합니다. 공유 폴더가 끊겨 있던 동안의 사용량도 다음 기록 때 합쳐서 올라갑니다.
  • 기록되는 것: 시각, 이름, PC 이름, 프로젝트 경로, 모델, 토큰 수, 한도 %. 대화 내용은 기록하지 않습니다. 프로젝트 폴더 이름은 공유 폴더 권한이 있는 사람에게 보입니다.
  • claude -p로 돌린 세션은 상태줄이 없어서 한도 칸이 비어 있습니다.
